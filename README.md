# Cub3D

Cub3D is a 3D game project created by afpachec and paude-so. It includes two main maps: a 3D version of the 42 Lisboa campus and a Wolfenstein 3D-inspired first-person shooter with enemies, weapons, collectibles, elevators, and multiple floors.

You can also play Cub3D directly in your browser at:  
https://omelhorsite.pt/en/games/cub3d

The game can be run locally or played on the web through a port using SDL and Emscripten.

## How to run locally

1. Clone the repository:

```bash
  git clone https://github.com/afonsopc/cub3d.git
  cd cub3d
```

2. Build the project:

```bash
  make
```

3. Run the game with a map:

```bash
  ./cub3d {map}
```

Replace `{map}` with the map file you want to load.
